Cada resultado se puede comprobar

Los resultados de CrashPY no se inventan en el momento: quedan fijados antes de jugar con criptografía (SHA-256), y después cualquiera los puede recalcular. Ni el casino puede cambiar una ronda o una jugada sin que se note.

¿Cómo funciona el Crash?

  1. Semilla secreta. El servidor genera una semilla al azar y le aplica SHA-256 una y otra vez, formando una cadena de hasta 1.000.000 de hashes.
  2. Se publica el final. El último eslabón (el hash terminal) se publica acá abajo antes de la primera ronda.
  3. Se juega hacia atrás. La ronda 1 usa el penúltimo hash, la ronda 2 el anterior, y así. Como SHA-256 no se puede revertir, nadie puede saber el hash de la próxima ronda, pero sí comprobar el de cada ronda terminada: SHA256(hash de la ronda) = hash de la ronda anterior.
  4. Del hash al multiplicador. El punto de explosión se calcula con una fórmula pública (ver abajo) usando el hash de la ronda y una sal pública. Todo se revela cuando la ronda explota.
  5. Rondas anuladas. Si el servidor se reinicia o el administrador detiene una ronda, la ronda queda marcada como anulada y nadie pierde su apuesta (se devuelve o se paga al multiplicador de ese momento). Su hash se publica igual.
Fórmula
hmac  = HMAC_SHA256(clave = sal, mensaje = hash_de_la_ronda)
r     = primeros 13 caracteres hex de hmac  (52 bits)
X     = r / 2^52
crash = floor( (100 − ventaja%) / (1 − X) ) / 100      (mínimo 1.00x)

const crypto = require('crypto');
function crash(hash, salt, edgePercent = 3) {
  const hmac = crypto.createHmac('sha256', salt).update(hash).digest('hex');
  const x = parseInt(hmac.slice(0, 13), 16) / 2 ** 52;
  return Math.max(100, Math.floor((100 - edgePercent) / (1 - x))) / 100;
}
const prev = (hash) => crypto.createHash('sha256').update(hash).digest('hex');
Python
import hmac, hashlib
def crash(game_hash, salt, edge_percent=3):
    h = hmac.new(salt.encode(), game_hash.encode(), hashlib.sha256).hexdigest()
    x = int(h[:13], 16) / 2**52
    return max(100, int((100 - edge_percent) / (1 - x))) / 100
prev = lambda h: hashlib.sha256(h.encode()).hexdigest()

Nota: el hash se aplica sobre el texto hexadecimal (UTF-8), igual que en cualquier calculadora SHA-256 online.

¿Cómo funcionan Minas, Penales y Plinko?

  1. Semilla del servidor. Antes de jugar, el servidor elige una semilla secreta para vos y te muestra su hash SHA-256 (en el juego: 🔐 Justo → Mis semillas). Con el hash publicado, la semilla ya no se puede cambiar.
  2. Tu semilla. Vos elegís tu propia semilla (o usás la que se generó al azar). Así el casino tampoco puede elegir resultados a su favor.
  3. Nonce. Cada jugada usa el siguiente número (0, 1, 2…), así cada resultado es distinto.
  4. Revelación. Cuando cambiás tus semillas, la del servidor se revela: comprobás que su SHA-256 es el hash que viste y recalculás cada jugada acá.
Números al azar
bytes  = HMAC_SHA256(clave = semilla_servidor, mensaje = "semilla_cliente:nonce:ronda")   (ronda = 0, 1, 2…)
número = b0/256 + b1/256² + b2/256³ + b3/256⁴      (cada 4 bytes → un número entre 0 y 1; 8 números por ronda)

💣 Minas:   se mezclan las 25 casillas (0 a 24) tomando del lote la posición floor(número × restantes);
            las primeras N casillas elegidas son las minas.
⚽ Penales: el arquero se tira en floor(número × 3) para cada uno de los 5 penales (0 izquierda, 1 centro, 2 derecha).
🔴 Plinko:  en cada fila, número < 0,5 → izquierda; si no → derecha. La casilla es la cantidad de "derechas".

const crypto = require('crypto');
function numbers(serverSeed, clientSeed, nonce, count) {
  const out = [];
  for (let round = 0; out.length < count; round++) {
    const b = crypto.createHmac('sha256', serverSeed).update(`${clientSeed}:${nonce}:${round}`).digest();
    for (let i = 0; i + 4 <= 32 && out.length < count; i += 4)
      out.push(b[i] / 256 + b[i + 1] / 65536 + b[i + 2] / 16777216 + b[i + 3] / 4294967296);
  }
  return out;
}
